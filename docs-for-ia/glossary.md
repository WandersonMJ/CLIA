# CLIA - Glossário de Termos

- CLIA: Copiloto de IA CLI autônomo, a aplicação central.
- Provedores de IA: GPUs-n. Gemini (Google), OpenAI (GPT), Claude (Anthropic).
- System prompt: regras e instruções contidas em system-prompt.md (pt-BR/en-US).
- History (conversa): conjunto de mensagens trocadas entre usuário, IA e ferramentas, usado para conduzir a conversa.
- Tool: ação exposta pela FS (filesystem-tools/fs-actions) que a IA pode solicitar para modificar código/arq.
